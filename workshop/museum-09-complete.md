# You did it!

You built Museum Exhibit Studio with the GitHub Copilot SDK, from your first curator session to an
interactive exhibit page. You took an agent beyond the software lifecycle and gave it a clear job,
a distinct voice, and boundaries owned by your application.

## What you brought together

- A streaming curator with a custom system message and educator-approved facts.
- Structural validation and scoped Wikipedia research, with captured citations kept separate
  from the approved facts.
- An interactive exhibit page created through a write permission restricted to `exhibit.html`.

Review the exhibit before sharing it with visitors. Structural checks do not prove factual
accuracy, and researched claims still need human review.
