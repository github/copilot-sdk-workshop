# Geschafft!

Sie haben Museum Exhibit Studio mit dem GitHub Copilot SDK erstellt, von Ihrer ersten
Kurator-Sitzung bis zu einer interaktiven Ausstellungsseite. Sie haben einen Agenten über den
Softwarelebenszyklus hinausgeführt und ihm eine klare Aufgabe, eine eigene Stimme und von Ihrer
Anwendung gesteuerte Grenzen gegeben.

## Was Sie zusammengebracht haben

- Einen streamenden Kurator mit benutzerdefinierter Systemnachricht und von der Lehrkraft freigegebenen Fakten.
- Strukturelle Validierung und eingegrenzte Wikipedia-Recherche, wobei erfasste Zitate getrennt von den freigegebenen Fakten gehalten werden.
- Eine interaktive Ausstellungsseite, erstellt über eine auf `exhibit.html` beschränkte Schreibberechtigung.

Prüfen Sie die Ausstellung, bevor Sie sie mit Besuchern teilen. Strukturprüfungen belegen keine
faktische Genauigkeit, und recherchierte Aussagen benötigen weiterhin menschliche Überprüfung.

## Weiterbauen

Probieren Sie ein neues von einer Lehrkraft freigegebenes Thema aus, oder passen Sie das
Kurator-Muster an eine andere Zielgruppe an. Halten Sie vertrauenswürdiges Quellmaterial, ergänzende
Recherche und generierte Texte klar getrennt.

Verwenden Sie unten **Zurück zum Workshop-Hub**, um Accessibility Reviewer in Ihrer ausgewählten
Sprache auszuprobieren, oder rufen Sie den vorherigen Schritt erneut auf, um Ihre Ausstellungsseite
zu verfeinern.
