# 해냈습니다!

첫 큐레이터 세션부터 대화형 전시 페이지까지 GitHub Copilot SDK를 사용하여 박물관 전시
스튜디오(Museum Exhibit Studio)를 완성했습니다. 에이전트를 소프트웨어 수명 주기 너머로
확장하여 명확한 역할과 고유한 목소리를 부여하고, 애플리케이션이 관리하는 경계를
설정했습니다.

## 하나로 결합한 요소

- 사용자 지정 시스템 메시지와 교육자가 승인한 사실을 사용하는 스트리밍 큐레이터
- 구조 검증과 범위가 제한된 Wikipedia 조사 및 승인된 사실과 별도로 보관되는 수집된 인용
- `exhibit.html`로 제한된 쓰기 권한을 통해 생성되는 대화형 전시 페이지

방문객과 공유하기 전에 전시를 검토하십시오. 구조 검사는 사실의 정확성을 입증하지 않으며,
조사를 통해 얻은 주장도 여전히 사람의 검토가 필요합니다.
